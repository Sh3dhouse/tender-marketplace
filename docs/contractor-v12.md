# SHP 1.2 contractor adapters

Invoice preferences are keyed by project ID in store.invoicePreferences. Future drafts snapshot supplier, registration choice, tax basis, due days, reference prefix, model and terms; changing preferences does not rewrite earlier invoices. Models are stage/milestone, cumulative progress valuation, time and materials, and fixed price. Progress valuations deduct prior cumulative claims exactly once. GST registered suppliers use 15% GST; inclusive input splits net/tax, exclusive input adds tax. Non-registered suppliers add no GST. Calculations round to cents. Invoice drafts remain unissued and unserved; payment details and statutory section 20/Form 1 review remain explicit.

Pricing model imports use sh-pricing-csv-v1 with exact header item_code,description,category,unit,quantity,unit_cost_ex_gst,markup_percent. UTF-8 decoding is strict; parser supports quoted cells, escaped quotes, CRLF and embedded newlines. Maximum 1 MB / 500 rows; identifiers must be unique and restricted to safe characters. Required strings and numeric cells are validated, formula-like text rejected. Quantity/unit cost limits 1,000,000, markup limit 1,000%, selling line limit NZD 100,000,000. Zero quantities are permitted. Line cost is rounded quantity times unit cost; selling is rounded cost times markup factor; GST is rounded selling times 15%.

Import requires a displayed validation preview and explicit button. Existing imported item codes update in the current project; manual lines remain. Source/revision/file/import timestamp provenance is stored. No XLSX import or live sync is claimed. The downloadable CSV includes two clearly fictional rows. This adapter is a foundation for the separate spreadsheet model under development. All cost confidentiality remains a UI-only browser demo boundary.

Verified via node syntax and module render smoke checks, including quoted CSV, decimal inputs, zero quantities, missing/negative cells, formula-like strings, inclusive GST split, cumulative prior deduction and time/material arithmetic. No shared files modified; no publishing or pushing performed by this agent.
