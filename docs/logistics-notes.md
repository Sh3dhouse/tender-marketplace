# SHP 1.2 staff logistics

Load `staff-logistics.js` and `staff-logistics.css`; the public module is `SHLogistics` with pages, render(page, ctx), bind(page, ctx). Context matches SHStaff plus optional asynchronous ctx.files helpers. Staff project selector stores staffProjectId. All shipment, inventory, incident and evidence reads/writes check project IDs. Supplier and upgrade registers are business-wide.

Shared records follow the supplied schemas. Supplier extension fields: rank (within material category), checkedAt (availability evidence date), updatedAt. Upgrade basis explicitly describes a positive customer delta over the contracted kitset; prices exclude 15% GST. No real supplier partners are invented. Shipment events always say Manual. Incidents extend hold, resolution and history. The customer module should set hold:true and shipment status On hold on reporting damaged, missing or unsafe material. Staff also places a hold when reporting on behalf of a customer. Staff progression blocks non-held milestones until active incident holds are assessed. Resolution requires recorded remedy/confirmation and clearing the hold; shipment remains held until a separate manual review updates it. This conservative separation prevents automatic installation clearance.

Incident attachment downloads use ctx.files.get(id) and require matching projectId and ownerId plus a Blob. No uploads, live carrier calls, claim filing or notification delivery are performed by this module. Files remain device-local through the shared root helpers.

Official Mainfreight research, checked 15 October 2026: [Getting started](https://developer.mainfreight.com/global/en/global-home/getting-started.aspx) describes Tracking API reference/event results, tracking links and proof of delivery, and registration/API key access. [Tracking update webhook](https://developer.mainfreight.com/global/en/global-home/subscription-api/tracking-update-webhook.aspx) describes reference, carrierReferences, trackingUrl and event fields. This supports a future credentialled server integration, not a live connection in the current preview. Production work needs server permissions, credential storage, secured webhook ingestion, shipment reference mapping and idempotent event handling.
